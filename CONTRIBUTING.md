# Contributing to FennecKit 🦊

First off, thank you for taking the time to contribute! 🎉 

Please take a moment to review this document in order to make the contribution process easy and effective for everyone involved.

---

## 🚀 How to Contribute

1. **Fork** the repo on GitHub.
2. **Clone** your fork to your local machine:
   ```bash
   git clone [https://github.com/Ruwantha-OFFICIAL/your-repo-name.git](https://github.com/Ruwantha-OFFICIAL/your-repo-name.git)

 * Create a new branch for your feature or bug fix:
   git checkout -b feature/amazing-feature
# (or)
git checkout -b fix/bug-fix-name

 * Make your changes and test them thoroughly.
📝 Updating the Changelog (CHANGELOG.md)
If your pull request adds a new feature, fixes a bug, or makes any notable changes, you must document it in the CHANGELOG.md file.
 * Open CHANGELOG.md.
 * Under the Unreleased section, add a brief description of your change under the correct category:
   * ### Added for new features.
   * ### Fixed for bug fixes.
   * ### Changed for changes in existing functionality.
   * ### Deprecated for soon-to-be removed features.
   * ### Removed for removed features.
Example entry:
## [Unreleased]
### Added
- Added user profile picture upload feature (#45) by @your-username

📦 Updating package.json Version
Along with your code changes and changelog entry, please update the version inside package.json following Semantic Versioning (SemVer):
 * Patch update (0.0.X): For minor bug fixes or small tweaks.
 * Minor update (0.X.0): For new features that are backward-compatible.
 * Major update (X.0.0): For breaking changes.
Locate the version field in package.json and bump it accordingly:
{
  "name": "your-project",
  "version": "1.1.1" // <-- Update this version number
}

📤 Submitting Your Pull Request
 * Commit your changes with a clear commit message:
   git commit -m "feat: add amazing new feature"

 * Push to your fork:
   git push origin feature/amazing-feature

 * Open a Pull Request on GitHub and describe your changes clearly.
Thank you for your contribution! ❤️
