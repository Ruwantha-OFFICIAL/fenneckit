Overview & Installation

FennecKit is a lightweight TypeScript and Node.js testing utility engineered specifically for sequential state-chained pipeline checks. Unlike standard unit testers, it maintains state across test steps.

Install the package locally into your development workspace via npm:

npm install fenneckit --save-dev

Quickstart Workflow

Create a test script ending in .spec.js or .test.js and configure your initial flow block:

import { newLabs } from "fenneckit";

await newLabs("Auth & User Flow", async (kit) => {
  kit.setStore("token", "jwt_abc123");
  kit.done("Step 1 Completed successfully.");
});

newLabs() API Reference

The newLabs method initializes an isolated execution lab with automatic logging and error handling.

function newLabs(labName: string, callback: (kit: LabContext) => Promise<void>): Promise<void>

Store & Secrets API

Use context methods to securely assign persistent runtime values across sequential steps:

kit.setStore("key", "value");
const val = kit.getStore("key");

kit.setSecret("db_pass", "secret_123"); // Encrypted AES-256-GCM

CLI Execution

Execute your test suites directly using the built-in npx binary runner:

npx fenneckit
